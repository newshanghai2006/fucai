开发一个简单的中国福利双色球的是否中奖的检查程序web页面，可以输入自己定义的10个以内的号码组，能够和近期的20期的双色球的结果进行比对，是否中奖，中奖结果在提交后显示。自己输入的号码组可以临时保存，这样下次可以不用继续输入（登录后的用户）。如果要登录的话，使用微信扫码或者其他的第三方登录就可以登录，登陆以后能临时保存自己输入的号码组，不登录的话其他功能都可用，只是不能保存输入的号码组。



双色球中奖检查器已完成开发并启动预览。
功能实现:
• 前端 (Vue 3 + Vite): 号码输入、微信扫码登录(模拟)、结果展示、号码保存
• 后端 (Node.js + Express + SQLite): 开奖数据API、用户认证、号码组CRUD
• 内置20期模拟开奖数据用于比对
• 完整的中奖判定规则(一至六等奖)
